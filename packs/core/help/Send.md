# Send

A tap that passes a stereo signal through untouched and sends a copy out at its own level.

Inlets 1-2 carry the signal; a cord into inlet 1 alone feeds both sides. Outlets 1-2 are the thru pair, identical to the input at all times, and outlets 3-4 are the same signal scaled by Level. Cord the thru pair on to the Mixer as before and the send pair into a Fern, a Verbatim, a Bus or a spare SoundOut, so an effect hears the signal without re-plumbing the patch. Bypassing the organism keeps the thru pair and silences the send, so killing a send never interrupts the dry signal.

## Parameters

**Level** How loud the copy on outlets 3-4 is, shown as Send Level. 1 sends at unity, 0 mutes the send and above 1 drives the effect harder; changes are smoothed, and the thru pair never changes.

## Recipe

**Reverb send** Put a Send between a voice and the Mixer, cord outlets 1-2 to the Mixer input it used before and outlets 3-4 into a Verbatim set fully wet, then cord the Verbatim to its own Mixer input. Start Level around 0.5 and raise it for more room; ride it up briefly for a throw on the last word of a phrase.
