# Verbatim

Un riverbero a convoluzione che fa suonare il tuo segnale attraverso una risposta all'impulso registrata.

Trascina o scegli un file d'impulso nella striscia in alto e tutto quello che ci colleghi succede dentro quella registrazione: una tromba delle scale, un riverbero a molla o una sala. Qualsiasi file audio funziona come impulso, fino a quindici secondi; i file fatti apposta suonano come stanze invece che come note. L'impulso viene normalizzato al caricamento, così file diversi arrivano a un livello paragonabile e Mix mantiene il suo significato. Il percorso effettato passa per Predelay, poi per Damp, poi per LowCut. Collegaci un Sampler, un Wave o un intero bus del Mixer, oppure mettilo sul ritorno di un Send.

## Parametri

**File** La risposta all'impulso attraverso cui suonare. Si carica qualsiasi file audio; vengono usati i primi quindici secondi.

**Mix** Secco contro effettato, a potenza costante. Tutto a sinistra è il segnale intatto, tutto a destra è solo la stanza.

**Predelay** Quanto aspetta la stanza prima di rispondere, fino a un quarto di secondo. Spinge lo spazio indietro, dietro il suono diretto.

**LowCut** Taglia le basse dell'effettato, dove le stanze lunghe diventano fango. Al minimo stabilizza solo l'estremo basso.

**Damp** Un passa-basso sul percorso effettato. Abbassalo e la stanza si scurisce, come se le pareti diventassero più morbide.

**Reverse** Suona l'impulso al contrario, così la stanza cresce verso la nota invece di decadere dopo.

## Ricetta

**Sala in mandata** Sul ritorno di un Send, Mix tutto a destra, Predelay 20, LowCut 150, Damp 6000. Carica l'impulso di una sala, manda voci e pad al Send e tieni fuori la batteria, così le basse restano secche.
