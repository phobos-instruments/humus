# Drops

Wassertropfen als Instrument: ein zufälliger Regen kleiner physikalischer Ereignisse, solange der Transport läuft.

Jeder Tropfen ist eine gedämpfte Sinusschwingung auf der Resonanz einer Blase, deren Tonhöhe beim Ausklingen steigt, und genau das lässt einen Tropfen nass klingen. Tropfen fallen zufällig, solange der Transport läuft, und hören auf, wenn er stoppt, und dasselbe Patch rendert jedes Mal denselben Regen, also hält ein Bounce keine Überraschungen bereit. Size legt die Blase fest, Spread, wie stark jeder Tropfen davon abweicht, und Pool legt eine kleine resonante Hallfahne unter den Regen. Schick es in ein Fern für Tropfen, die sich selbst antworten, oder in ein SoundSpace für eine Höhle.

## Parameter

**Density** Tropfen pro Sekunde. Ein Leck bei 1, Regen bei 8, ein Wolkenbruch bei 20.

**Size** Die Größe der Blase. Links sind es kurze, helle Ticks, rechts dicke Tropfen mit echter Tonhöhe.

**Spread** Wie stark jeder Tropfen von Size abweicht. Bei null ist jeder Tropfen ein Klon; ganz aufgedreht regnet es alle Größen auf einmal.

**Chirp** Der Pitch-Bend nach oben in jedem Tropfen. Bei null sind die Tropfen schlichte Pings; ab der Mitte blubbern sie.

**Pool** Eine kleine resonante, nasse Hallfahne unter dem Regen. Trockener Stein bei null, eine Zisterne bei eins.

**Width** Wie weit über das Stereofeld verteilt die Tropfen fallen.

**Level** Ausgangslautstärke.

## Rezept

**Langsames Leck** Density 2, Size 0.8, Spread 0.3, Chirp 0.8, Pool 0.5, Width 0.7. Schick es durch ein Fern mit Feedback um 0.5, und jeder Tropfen kehrt einen Schlag später zurück. Dreh Density auf 15 und Size runter auf 0.2 für Regen am Fenster.

## Verwandte Organisms

SoundSpace, Fern, Morse
