# Notes

A text box on the canvas that makes no sound and has no pins.

Use it to leave instructions for whoever opens the patch next: what the patch is for, which knob to touch first, what an input expects, why an organism sits where it does. Rename the box and the name becomes the note's headline. It is an organism like any other, so it moves with a selection, lives inside a pod and saves with the patch. Nothing cords to it; place it beside the organisms it describes.

## Parameters

**Text** The body of the note. Type straight into the box.

## Recipe

**Start-here note** Drop a Notes beside the SoundIn, rename it "Start here" and write the order to switch things on and the one knob that shapes the patch. Put a second one inside any pod whose input is not obvious.
