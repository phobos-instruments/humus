# Samples

One sound per file, for the Sampler and anything else that reads a single hit.
The Sampler's slots take a file each; a folder here is a kit only by
convention, and the browser shows the folder name as its group.

Takes `.wav`, `.aif`, `.aiff` and `.flac`. `Documents/Humus/assets/Samples/` is
read first, so your own files win by name.

**Empty in the source distribution.** The released app bundles a ten-piece
analog drum kit recorded from one machine's individual outputs and dedicated to
the public domain; the zip carries the code, not the content. Public-domain
drum machine recordings are widely available, and a kit is ten files - point
the Sampler at whatever you already have.
