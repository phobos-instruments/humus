# Impulses

Impulse responses: a recording of a room, a plate or a spring. Verbatim's
browser lists whatever is here, grouped by the folder each file sits in - the
folder name is the badge it shows, so `Room/`, `Cabinet/` and `Spring/` are
suggestions rather than fixed names.

Takes `.wav`, `.aif`, `.aiff` and `.flac`. Drop files in and restart, or use
your own folder instead - `Documents/Humus/assets/Impulses/` is read first, so
a file of yours wins by name and an update cannot overwrite it.

**Empty in the source distribution.** The released app bundles fourteen, which
are somebody else's recordings under a licence that asks for credit; the zip
carries the code, not the content. Collections of freely licensed responses are
easy to find - look for public-domain or Creative Commons reverb impulse sets,
and mind that a licence asking for attribution asks it of you too once you
publish something made with them.
